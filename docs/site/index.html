cinzel

/sĩˈzɛl/ · Portuguese for chisel

cinzel converts CI/CD pipelines between HCL and YAML, in both directions.

Write GitHub Actions workflows or GitLab pipelines as HCL — where a step is defined once and reused by name — and cinzel writes the YAML each platform expects. Point it at the pipeline you already run to get the HCL to start from.

Apache-2.0

The problem

A step used by several workflows is written out once per workflow. Nothing connects the copies, so they drift.

.github/workflows/ci.yaml
jobs:
  test:
    steps:
      - uses: actions/checkout@v4
.github/workflows/nightly.yaml
jobs:
  soak:
    steps:
      - uses: actions/checkout@v3

The nightly build is a version behind. It has been for months. You find out when it breaks.

In HCL

The step is a block. Jobs refer to it by name, so there is one copy and one version.

cinzel/steps.hcl
step "checkout" {
  uses {
    action  = "actions/checkout"
    version = "11d5960a3267" # v4
  }
}
cinzel/jobs.hcl
job "test" {
  steps = [step.checkout, step.unit]
}

job "soak" {
  steps = [step.checkout, step.load]
}

Then cinzel github parse writes .github/workflows back out. Bump the version in one place and every job moves with it.

Commands

Both providers, both directions.

cinzel github unparse Turns the YAML you already run into HCL, so you start from a working pipeline rather than a blank file.
cinzel github parse Turns the HCL back into YAML. Comments survive — above a block, beside a value, closing a body.
cinzel github diff Reports what parse would change, and writes nothing. Exits 1 when the committed YAML has drifted, so CI can fail on it.
cinzel github pin Rewrites every action tag as the commit SHA it points at, keeping the tag in a comment. upgrade bumps first, then pins.
cinzel gitlab … The same two directions for .gitlab-ci.yml. GitLab's HCL is its own — jobs, templates, includes and the pipeline keywords, not GitHub's blocks.
cinzel github assist Generates a pipeline from a prompt, through the same conversion path. Blocks you already have are referenced, not duplicated.

Install

macOS, Linux and Windows. No runtime, no configuration to start.

$ brew tap yldio/cinzel && brew install --cask cinzel $ go install github.com/yldio/cinzel@latest

Or download a binary from the releases page.
